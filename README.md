# 🇨🇦 Proof of Funds Calculator - Canadian Immigration

A dynamic interactive simulator developed to help future immigrants calculate the financial settlement funds required for the main Canadian immigration programs (Express Entry, Atlantic, and Rural), featuring real-time currency conversion.

## ✨ Features

* **Family Size Calculation:** Dynamic logic that adjusts CAD$ requirements based on the number of family members entered by the user.
* **Real-time Exchange Rate:** Integrated with an external API to fetch the most current Canadian Dollar (CAD) to Brazilian Real (BRL) rate.
* **Savings Converter:** A built-in tool to instantly convert current savings from BRL to CAD.
* **Bilingual Support:** Full versions available in both Portuguese and English to serve a global audience.
* **Responsive Design:** Interface optimized for quick consultation on mobile devices, tablets, and desktops.

---

## 🛠️ Technologies Used

This project was built focusing on data precision and clean performance:

* **HTML5:** Semantic structure for better accessibility and SEO.
* **CSS3:** Modern layout using **Flexbox** and **Grid**, focusing on clear information cards and scannable data.
* **JavaScript (ES6+):** * API consumption via `fetch` with asynchronous functions (`async/await`).
    * Dynamic DOM manipulation to update values without page refreshes.
    * Mathematical logic to handle fund progression according to specific immigration program rules.
* **Exchange Rate API:** [AwesomeAPI](https://docs.awesomeapi.com.br/) (CAD-BRL currency pair).
